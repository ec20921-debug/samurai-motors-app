## このフォルダの使い方

### 🟢 出張前にやること
1. `00_background.md` — 前回からの経緯
2. `01_objectives.md` — 今回の目的
3. `02_agenda.md` — 日次アジェンダ・フライト
4. `notes/onsite-tasks.md` — 現地タスク（★今回のアジェンダ本体）

### 🟡 出張中の運用
- **毎朝**: `daily/dayN_YYYY-MM-DD.md` の「今日の予定」を書く
- **随時**: イベントが起きたら Claude Code に投稿（写真は `photos/dayN/`）
- **毎晩**: 「dayN を整理して」と依頼 → 1日分のログが整う

### 🔴 帰国後
- 「最終レポート作って」と依頼 → `REPORT.md` を写真付きで自動生成
