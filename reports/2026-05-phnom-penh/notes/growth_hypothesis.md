## 1. 問題設定

- **新規予約**: 過去1ヶ月でゼロ
- **既存顧客**: リピート利用あり（信用済みの層は機能している）
- **露出**: Facebook ページ運用 + 業務車両の街中露出 + Telegram Bot 設置済み

→ 「届いていない」or「届いても刺さらない」のどちらか、あるいは両方。

## 2. 中心仮説

> **カンボジア市場におけるコンバージョン律速は「認知」ではなく「信用 → 予約」の最後の一歩である**

### サブ仮説

| ID | 内容 | 根拠 |
|---|---|---|
| A | 言語×声の壁 — クメール語の **テキスト ≠ 音声**。Telegram ボイスメッセージ文化が前提 | カンボジアの Telegram/WhatsApp 利用形態は音声中心 |
| B | 「誰」が言うかの壁 — 外国人ブランド × アプリ＝距離感MAX。ローカル媒介者が必要 | 後述の Huy さんケース |
| C | 過去の歴史背景による社会信用構造 — 内戦後の社会信用低下、身内・知人ベースの取引文化 | 鈴木の現地観察 |

## 3. 証拠

### 証拠 #1: Grab ドライバー Huy Kearvak さんのケース（2026-05-18）

| 段階 | 内容 | 結果 |
|---|---|---|
| 露出 | 過去4人のドライバーに同じ提案 | 0/4 受諾 |
| 提案（英語） | 鈴木が英語で説明 | 反応薄 |
| 提案（クメール語） | ロン君に電話を渡してクメール語で説明 | **受諾** |
| 結果 | ガラス3面 + ミラー無料施工が成立 | 1/1 |

**ドライバー情報**:
- 名前: Huy Kearvak（5.0★）
- 車両: Grey BYD Sealion 5 / PP-2CF-6485
- Grab 登録: 2025-08

**フローからの読み取り**:
- 信用転送のスイッチ = **クメール語 + ローカル人の声**
- 同じ提案内容でも、媒介者が変わると受諾率が 0% → 100% に振れた
- → 中心仮説（信用律速）を強く支持する初期データ

詳細は [`../daily/day0_2026-05-18.md`](../daily/day0_2026-05-18.md) を参照。

## 4. 検証実験

### 実験 1: 予約Bot にボイスメッセージ受付を追加

| 項目 | 内容 |
|---|---|
| 仮説 | テキスト予約への心理的ハードルがあり、ボイス受付があればコンバージョンが上がる |
| 変更内容 | 予約Bot 起動時に「ロン君に声で話す」ボタンを追加 → ユーザーがクメール語ボイスを送信 → ロン君が折り返し |
| 実装場所 | `CustomerChat.gs` にボイスメッセージ転送ロジック追加 |
| 期間 | 2 週間 |
| 成功条件 | ボイス経由の予約コンバージョン率 > テキスト経由 + 5pt |
| コスト | 開発 1-2 日 |
| 副次効果 | クメール語識字に頼らない流入経路を確保 |
| **現場との一致** | 2026-05-18: 鈴木が現場で**全く同じ方向性を独立に提案**（[`system_issues.md`](./system_issues.md) #3 案 B）→ 仮説の妥当性が現場直感からも裏付けられた |

### 実験 2: TikTok でロン君主演のデモ動画

| 項目 | 内容 |
|---|---|
| 仮説 | ロン君の顔 + 声が信用転送の媒介になり、TikTok 経由で「初見でも信用」される層が現れる |
| 変更内容 | ロン君主演で 30 秒 Before/After 動画を週 2 本投稿（4 週間） |
| 役割分担 | 撮影=現場（ロン君）、編集=日本側（鈴木） |
| 期間 | 4 週間 |
| 成功条件 | TikTok 経由インバウンド ≥ 1 件、エンゲージメント率 > 5% |
| コスト | 編集ソフト無料、撮影スマホ完結 |

### 実験 3: ライドシェアドライバー戦略

| 項目 | 内容 |
|---|---|
| 仮説 | Grab / PassApp / Tada のドライバーは「動く口コミ装置」。彼らに無料施工 → 後部座席で他客に語ってもらう |
| 変更内容 | ドライバー10名に**条件付き無料ガラス施工**を提供。条件: ① クメール語ボイステスティモニアル、② SAMURAI ステッカー貼付承諾、③ 名刺渡し |
| 期間 | 6 週間 |
| 成功条件 | ドライバー経由の紹介で実予約 ≥ 3 件 |
| コスト | 1 施工あたり原価のみ（数ドル）× 10 台 = $30-50 程度 |
| 副次効果 | ドライバー自身が SNS フォローしてくれれば長期接点に |
