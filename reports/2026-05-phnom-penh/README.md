- **期間**: 2026-05-18(日)夜 出発 〜 2026-05-23(金)夜 帰国
- **現地滞在**: 2026-05-19(月) 〜 2026-05-22(木) の4日間 + 5/23(金)昼まで
- **目的地**: カンボジア・プノンペン
- **主担当**: Samurai Motors 関連業務

---

## このフォルダの使い方

### 🟢 出張前（〜5/17）にやること
1. `00_background.md` — 出張に至る背景・前回からの経緯を埋める
2. `01_objectives.md` — 今回の目的・達成したいことを埋める
3. `02_agenda.md` — 日次アジェンダ・アポイント先を埋める

> Claude Code のチャットで「目的はこういう感じ」「水曜にAさんと会う」と話せば、私の方で該当ファイルに反映します。

### 🟡 出張中（5/18〜5/23）の運用
- **毎朝**: `daily/dayN_YYYY-MM-DD.md` の「今日の予定」を書く
- **随時**: イベントが起きたら Claude Code に投稿（「今〇〇した」「△△で困った」）
  - 写真は `photos/dayN/` に保存（命名例: `1430_KandalMarket_客.jpg`）
- **毎晩**: 「day3 を整理して」と依頼 → 1日分のログがファイルに整う

### 🔴 帰国後（5/23夜〜）
- 「最終レポート作って」と依頼 → `REPORT.md` を写真付きで自動生成
- スプレッドシート / Notion / 業務 Bot 等に流す用の要約も別途出せます

---

## 運用のコツ（v6 の失敗から得た教訓を流用）

1. **毎晩 day*.md を確定させる** — 翌朝になると細部を忘れる。1日1コミット推奨
2. **写真は厳選 2〜3 枚/イベント** — Before/After ルールと同じ発想。多すぎるとレポート化が破綻
3. **「問題 → 対処 → 学び」をセットで残す** — 次回出張で生きる資産になる
4. **コンテキストが膨らんできたら都度サマリーを依頼** — 1セッション肥大化を防ぐ
