# 週次キャンペーン配信プラン作成スキル

Samurai Motors（カンボジア・プノンペンの出張洗車）の **1週間分のTelegram配信予定**を、
A4一枚（日本語＋クメール語併記）にまとめる。毎週の定例前に準備し、社内・現地スタッフで共有する。

## 使うタイミング
- 毎週の定例ミーティング前
- ユーザーが「今週/来週の配信」「週次プラン」「定例の配信表」等と言ったとき

## 成果物
1. **Markdown**: `docs/marketing/weekly_campaign/YYYY-Www_Month-WN.md`（例 `2026-W23_June-W1.md`）
2. （任意）**Googleドキュメント**: ec20921 の Drive に同内容を作成し共有リンクを返す
   - workspace-mcp の `create_drive_file`（mime=Google Doc）or `import_to_google_doc` を使用
   - 認証切れのことがあるので、失敗したら Markdown だけ確定し Doc 化は後回しでよい

## 手順

### 1. 対象週を確定（最重要・推測しない）
- 「今週」「来週」が何月何日（月〜土）かを**カレンダーで厳密に**確定する。
- 月曜=週初、土曜=週末。日曜は定休日なので配信対象外。
- ISO週番号（Www）も付ける。曖昧なら必ずユーザーに確認。

### 2. 前提情報を集める（足りなければ質問）
- 今週の**主目的**（ローンチ/通常運用/特定キャンペーン/季節要因）
- **特価・オファー**（例: $5 Wash / $10 Wash+Glass）と**期限の有無**
- **休業日・イベント**（スタッフ休み、祝日、貸切等）
- 直近の**売上/反応の状況**（売上ゼロなら獲得フェーズの設計に寄せる）
- 既知のターゲット属性（下記参照）

### 3. 配信スケジュールを設計
- **基本は毎日1通、必要に応じて2通**（朝＋夕）。
- 推奨時刻: **朝 08:00**（Grabドライバー待機＋住民の朝）、**夕 18:30**（Telegram閲覧ピーク）。
- ⚠️ 時刻は必ず **00/15/30/45 刻み**（GASの15分トリガーと一致させるため。`CampaignScheduler` 仕様）。
- 1週間で**全ターゲット属性を最低1回**は叩く配分にする。
- 季節（雨季=ガラス撥水）や曜日（週末=出張便利/Grab）を絡める。

### 4. コピーを書く（クメール語＋英語の2言語セット）
- ⚠️ **【必須・最初に実行】** クメール語を書く前に必ず
  **`docs/marketing/khmer-phrasing-reference.md`（自然な言い回しリファレンス）を読む**。
  抽出パターン（`លោកអ្នក`/`ផ្តល់ជូន`/`សូម…`/`តើ…មែនទេ?` 等）と語彙メモに沿って書く。
  これを飛ばすと「クメール語がおかしい」問題が再発する。スキップ禁止。
- 各配信は**クメール語と英語を1通にまとめる**（システムのデフォルト言語設定）。
- CTAは原則「**メッセージください / ផ្ញើសារមកយើង**」（特価は手動対応のため。アプリ予約に誘導しない）。
- 絵文字を程よく。1通は短く（Telegram で読み切れる長さ）。
- ⚠️ クメール語はドラフト。**ネイティブ確認（Bopha/ロン）を促す注記**を必ず入れる。

### 5. 2価格分離の原則を厳守（重要）
- Telegram限定特価（$5/$10等）は**コピーに書くだけ**。
- **料金設定/メニューシート/ミニアプリには絶対に入れない**（公開客に漏れる）。
- A4内に「ミニアプリは通常価格のまま」の注意書きを必ず入れる。

### 6. 休業日対応を明記
- スタッフ休み/休業日があれば、**Googleカレンダー終日イベントで予約アプリをブロック**する必要を明記。
- 告知だけだと「休みなのにアプリ予約が入る」矛盾になる（6/3祝日でない水曜の例）。
- チェックリストに入れる。

### 7. A4テンプレに流し込む（下記構成）
1. タイトル（年・第N週・日付範囲）日＋クメール
2. 今週のテーマ / オファー
3. 配信スケジュール表（日/曜/時刻/内容/通数）＋ 時刻の方針
4. 休業日対応（あれば）
5. 配信文（曜日ごと、クメール語＋英語の2言語セット、コードブロックで）
6. ターゲット属性メモ
7. 定例前チェックリスト
8. 今週のKPI

### 8. 仕上げ
- Markdown を保存。
- （可能なら）Google Doc 化して共有リンクを提示。
- 「キャンペーン予約」シートへの登録は**別タスク**（ユーザー承認後）。このスキルは"計画書作成"まで。
- 最後に「次アクション: 予約シート投入 / 6/3カレンダーブロック / コピーのBopha確認」を提示。

## ターゲット属性（既知・トゥールコーク高級住宅街中心）
- 🏠 高級住宅街の住民 → 品質・便利さ訴求
- 🎓 高校生（住民の子供）→ 手軽さ・価格
- 🚕 Grabドライバー → 実利「綺麗な車＝高評価」
- 🌧️ 雨季は全属性にガラス撥水が刺さる

## 固定情報（参照）
- サービス: Samurai Wash（無水洗車＋タイヤワックス）通常 $12〜/ Samurai Glass（撥水）アドオン
- 出張無料 or +$2（その週の設定で確認）
- 定休: 日曜
- システム: 予約は Telegram 予約Bot、キャンペーン配信は「📢 キャンペーン」メニュー
- 関連: `docs/marketing/weekly_campaign/`（過去の週次プラン）、`SPEC_CampaignBroadcast.md`
- **クメール語リファレンス（執筆前に必読）: `docs/marketing/khmer-phrasing-reference.md`**

## 出力時の注意
- 日本語ビジネス文書として整える。現地スタッフ向けにクメール語併記。
- 数字（日付・時刻・価格）は推測せず確定値を使う。曖昧なら質問。
- 真田の人格で簡潔に。作成後、変更影響と次アクションを添える。
