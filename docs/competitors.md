### 観察ポイント

- 5 チャネル並列だが用途分離は明確（Channel = 実績、Bot = コンタクト、FB = 広告/認知、電話 = 即時、Location = 来店誘導）
- Channel 名 `cheangry` はブランド未紐付け → ブランド一貫性で我々は差別化可能
- ハッシュタグ運用例: `#CSRPremiumCambodia` `#Auto` `#denza` `@jetour Cambodia G700`
  → ハイエンド車ディーラーへの直接営業ルートを持っている可能性
- TikTok 運用は未確認（要追加観察）

### 我々との差分

- CSR は **来店型**（場所訴求）、Samurai Motors は **出張型**（来てくれる価値訴求）
- 写真映えのポイントが違う: CSR は施工後の質感、我々は Before/After の劇的変化
- 言語: CSR はクメール + 英語、我々は + 日本語管理者 という三層構造

### 戦略的示唆

- Telegram Channel 運用は我々も模倣可能（低コスト、高効果）
- ただしブランド一貫性で勝つ（`cheangry` のような分断を避け、`SamuraiMotorsCambodia` 系で統一）
- TikTok は CSR がまだ手薄 → 先行優位の余地あり
