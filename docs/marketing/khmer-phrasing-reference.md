# クメール語 言い回しリファレンス（Khmer Phrasing Reference）

> 目的：Samurai Motors の顧客向けクメール語（予約Botのチャット、チラシ、キャンペーンコピー等）を
> **ネイティブが見て自然な言い回し**にするための参照集。
> 「クメール語がおかしい」と言われる問題を減らすため、実際にカンボジア人が作った
> プロのマーケティング素材から、良い表現・言い回しのパターンを蓄積していく。
>
> ⚠️ このファイルは顧客対応系の言語ルール（CLAUDE.md「🌐 言語ルール」）を補完するもの。
> 顧客向け＝クメール語メイン＋英語補足、という大原則は変わらない。
>
> 🔗 **仕組み化済み**：クメール語で外部発信するときは本ファイル参照を**必須化**している。
> - `CLAUDE.md` →「📖 クメール語を書く前の必須ルール」
> - `.claude/skills/weekly-campaign-plan/SKILL.md` → 手順4（コピー執筆）の最初に参照を強制

---

## 📌 使い方

- 顧客向けクメール語を書くとき、まずこのファイルの表現集を見る。
- 新しい良い素材（チラシ・他社広告・ネイティブが書いた文）を見つけたら、ここに追記する。
- 「自然な言い回し」のストックを増やすほど、出力の品質が上がる。

## 🗂 サンプル 01：Energy 88 EV充電ステーション パートナー募集チラシ

カンボジア（プノンペン）のローカル企業が制作した B2B 募集チラシ。
広告コピーとしてのクメール語のトーン・敬語・呼びかけが参考になる。

### 見出し・キャッチコピー

| クメール語 | 読み/意味（日本語） | ポイント |
|---|---|---|
| សហការជាមួយយើង | スハカー・ジア・ムオイ・ヨーン「私たちと協力しよう」 | `សហការ`(協力)＋`ជាមួយ`(～と一緒に)＋`យើង`(私たち)。勧誘の定番形。 |
| តើលោកអ្នកមានដីទំនេរ ឬទីតាំងល្អមែនទេ? | 「あなたは空き地、または良い立地をお持ちですか？」 | `តើ…មែនទេ?` で丁寧な疑問文を作る枠。`លោកអ្នក` は丁寧な二人称（→下記） |
| យើងផ្តល់ជូន | 「私たちが（あなたへ）ご提供します」 | `ផ្តល់ជូន` ＝「ផ្តល់(提供)＋ជូន(敬意の方向助詞)」。**広告は `ផ្តល់ជូន` が自然**。`ផ្តល់`単独より丁寧。 |
| លោកអ្នកផ្តល់ទីតាំង យើងផ្តល់សេវាកម្ម និងការដំឡើង! | 「あなたは立地を、私たちはサービスと設置を提供！」 | 対句（あなた↔私たち）でリズムを作る広告の王道。 |
| ចាប់ផ្តើមអាជីវកម្ម EV ជាមួយយើងថ្ងៃនេះ | 「今日、私たちと一緒に EV ビジネスを始めよう」 | `ចាប់ផ្តើម…ថ្ងៃនេះ`（今日始めよう）は行動喚起(CTA)の定番。 |
| ដើម្បីឈានទៅអនាគតនៃយានយន្តអគ្គិសនី | 「電気自動車の未来へ歩み出すために」 | `ឈានទៅ`(踏み出す/前進する)＋`អនាគត`(未来) はビジョン訴求の常套句。 |
| ទំនាក់ទំនងផ្ទាល់មកយើងតាមរយៈ | 「直接、下記の方法で私たちへご連絡を」 | `ទំនាក់ទំនង`(連絡)＋`ផ្ទាល់`(直接)＋`តាមរយៈ`(～を通じて)。連絡先の前置きの定番。 |

### 提供内容（箇条書きの書き方）

| クメール語 | 意味 |
|---|---|
| សេវាកម្មដំឡើង EV Charger | EV充電器の設置サービス |
| បច្ចេកវិទ្យាទំនើប និងមានសុវត្ថិភាព | 最新技術かつ安全 |
| ការគាំទ្រ（ថែទាំ）បច្ចេកទេស | 技術サポート／メンテナンス |
| ដំណោះស្រាយអាជីវកម្ម EV ពេញលេញ | 完全な EV ビジネスソリューション |

### 信頼訴求（フッターのアイコン文言・読み取りベース）

> ⚠️ 画像が小さく一部は推定。引用時は要確認。

- ទិន្នផល / ប្រាក់ចំណេញ（収益・利益）
- ថែរក្សាបរិស្ថាន / ទ្រទ្រង់បរិស្ថាន（環境保全・環境にやさしい）
- អាជីវកម្មជាក់ស្ដែង មានស្ថិរភាព（堅実で安定したビジネス）
- រួមចំណែកជួយបរិស្ថាន និងធម្មជាតិ（環境と自然への貢献）

## 💡 抽出された「自然なクメール語」パターン

このチラシ全体から、Samurai Motors の顧客向けコピーに転用できる汎用パターン：

### 1. 二人称は `លោកអ្នក`（丁寧）

- `លោកអ្នក` ＝ 顧客・お客様への丁寧な呼びかけ。広告・接客の標準。
- カジュアルな `អ្នក` 単独より敬意があり、ビジネス顧客向けに最適。
- Samurai Motors の予約Botでも顧客への呼びかけは `លោកអ្នក` を基本にすると自然。

### 2. 「提供する」は `ផ្តល់ជូន`（敬語方向の `ជូន` を付ける）

- `ផ្តល់ជូន` / `ផ្ញើជូន` / `បញ្ជូនជូន` のように、顧客に何かを渡す動詞には `ជូន` を添えると丁寧。
- 例：QR送信通知 →「យើងបានផ្ញើ QR ជូនលោកអ្នក」（QRをお客様へお送りしました）

### 3. 疑問文は `តើ … ?` / 丁寧確認は `… មែនទេ?`

- `តើ` を文頭に置くと丁寧な疑問になる。`មែនទេ?`（～ですよね？）で確認のニュアンス。
- 例：「予約日でお間違いないですか？」→「តើថ្ងៃកក់ត្រឹមត្រូវមែនទេ?」

### 4. CTA は「動詞＋ជាមួយយើង＋ថ្ងៃនេះ/ឥឡូវនេះ」

- `…ជាមួយយើង`（私たちと一緒に）＋ `ថ្ងៃនេះ`（今日）/ `ឥឡូវនេះ`（今すぐ）で行動喚起。
- 例：「今すぐご予約を」→「កក់ឥឡូវនេះ ជាមួយ Samurai Motors」

### 5. 対句でリズムを作る

- 「あなたが○○、私たちが△△」のような対句は読みやすく説得力がある。
- 例：「お客様は待つだけ、洗車は私たちにお任せ」
  →「លោកអ្នកគ្រាន់តែរង់ចាំ ការលាងសម្អាតសូមទុកឲ្យយើង」

### 6. 連絡先の前置き `ទំនាក់ទំនងមកយើងតាមរយៈ`

- 電話・Telegram などの連絡先を載せる前の定番フレーズ。

|---|---|---|
| ご提供します | ផ្តល់ជូន | `ជូន` で敬意 |
| ご連絡 | ទំនាក់ទំនង | |
| 直接 | ផ្ទាល់ | |
| ～を通じて | តាមរយៈ | |
| サービス | សេវាកម្ម | |
| 始める | ចាប់ផ្តើម | |
| 今日 | ថ្ងៃនេះ | |
| 今すぐ | ឥឡូវនេះ | |
| お客様（丁寧） | លោកអ្នក | |

| 安心・品質 | គុណភាព | |

## 🗂 サンプル 02：WURKZ（ワークウェア・ブランド）Facebook 協賛キャンペーン投稿

カンボジアの作業着／ワークウェアブランド **WURKZ** の Facebook 投稿（協賛・giveaway告知）。
EVチラシ（B2B・落ち着いた敬語トーン）とは対照的に、**力強く煽る販促トーン**が参考になる。
スローガン `#UNSTOPPABLE` を前面に出すブランドボイス。

> ⚠️ **書き起こし注意**：元画像は解像度が低く、本文（キャプション）は小さく/ぼやけて
> 正確に判読できない。下記は**はっきり読める部分のみ**。正確な全文が必要なときは
> 投稿のキャプションをテキストで貼ってもらうこと（推定で埋めない）。

### 確実に読めるフレーズ / 意味

| クメール語 | 意味 | ポイント |
|---|---|---|
| ប្រកាសឧបត្ថម្ភ | 「協賛を発表する／スポンサーします」 | `ប្រកាស`(発表する)＋`ឧបត្ថម្ភ`(支援・協賛)。CSR・スポンサー・giveaway告知の定番。 |
| ដើម្បីជួយ … | 「～を助けるために」 | `ដើម្បី`(～のために)＋`ជួយ`(助ける)。社会貢献・支援目的を述べる枠。 |
| $35,000 / $250,000 | 金額 | **大きな数字を主役に**して目を引く構図。 |

### ブランドボイスの観察（転用ポイント）

- **数字を主役に**：協賛額・割引額・台数などの数字を一番大きく見せる。
- **英語スローガンを混在**：`#UNSTOPPABLE` のように短い英語キーワードを混ぜて勢いを出す。
  → Samurai Motors でもキャンペーンの強い見出しは「クメール語＋短い英語キーワード」が有効。
- **`ប្រកាស…`（～を発表）**：新サービス・新キャンペーン・割引の告知冒頭に使える。
  例：「新キャンペーンを発表！」→「ប្រកាសយុទ្ធនាការថ្មី!」
- EVチラシの `លោកអ្នក`（丁寧）とは違い、煽り系は二人称を省いて命令形・体言止めでテンポを作る。
  → **顧客向けは原則 EVチラシ系の丁寧トーン**を基本にし、キャンペーン見出しだけ WURKZ 系の勢いを借りる、と使い分ける。
