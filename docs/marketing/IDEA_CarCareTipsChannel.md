## 1. 背景・狙い

日本では当たり前でも、カンボジアではまだ知られていない**車に関する知識**は多い。これを **毎週水曜に自動配信**し、

> 「登録しておくだけで、車に詳しくなれる」

というチャンネルを育てる。狙いは販売の直接訴求ではなく、

- 🏆 **Samurai Motors＝車のプロ** というブランド権威の確立
- 🔁 接点を毎週持つことで**リピート・紹介**につなげる
- 📣 Facebook 集客の受け皿となる**オウンドメディア（自社資産）化**

「安い路上手洗いとは違う、知識のある専門店」という差別化にも直結する。

---

## 2. 重要な前提整理 — きっかけの記事とは別物

本案のきっかけは [Claude Code Channels の記事](https://qiita.com/kai_kou/items/bc6bb4f86f46aca90eab) だが、**記事の機能はこの用途には使わない**。

| 用語 | 実体 | 本案に使う？ |
|---|---|---|
| Claude Code **Channels** | スマホから自分のPCのClaude Codeを遠隔操作する開発者用リモコン（許可リスト制） | ❌ 用途が違う |
| Telegram の**チャンネル** | 登録者に一斉放送するTelegram標準機能 | ✅ **これが正解** |

同じ「チャンネル」でも別物。さらに **自動配信は「PCが消えていてもクラウドで毎週動く」ことが必須**で、PC常駐前提の Claude Code Channels は不向き。→ **GAS の時刻トリガーが最適**。

## 3. 既存の配信施策との関係（重複しない・補完する）

| | 🟦 月曜：販促配信（実装済） | 🟩 水曜：教育配信（本案・新規） |
|---|---|---|
| 目的 | 来店・注文の獲得（セール） | 知識提供・ブランド育成 |
| 内容 | 30%オフ／限定特価など | カーケア豆知識 |
| 経路 | Bot → 既存客の**個別DM** | Bot → **公開チャンネル**（放送） |
| 対象 | Botを開始済みの既存客（約50名） | チャンネル登録者（**誰でも・無制限に拡張可**） |
| 既存資産 | `v7/Campaign.gs`, `SPEC_CampaignBroadcast.md` | 新規（本案） |

ポイント：販促DMは「既存客」止まりだが、**公開チャンネルは Facebook 等から新規にも広がり、Bot未開始の人にも届く**。レート制限（429）の心配も少ない。販促（月）と教育（水）で**役割を分ける**。

## 4. 仕組み（構成）

```
📋 カーケア記事ストック（スプレッドシート：クメール語＋英語で蓄積）
        │
        ▼
⚙️ GAS 週次トリガー（毎週水曜 朝9時 ICT）   ← 既存 checkUnpaidReminders 等と同じ時刻トリガー
        │  次の1本を取り出す
        ▼
🤖 Bot（チャンネルの管理者として投稿）       ← TelegramAPI.gs の sendPhoto / sendMessage を流用
        │
        ▼
📢 Telegram公開チャンネル「Samurai Motors Car Care」
        │
        ▼
👥 登録したカンボジア人顧客に自動で届く
```

必要要素はほぼ既存資産で揃う：

- ✅ GAS 時刻トリガー（毎週・曜日指定可）
- ✅ Telegram Bot API（Botをチャンネル管理者にすれば投稿可能）
- ✅ スプレッドシート連携
- 🆕 新規で作るのは「公開チャンネル」＋「週次トリガー関数1本（数十行）」＋「ネタ管理タブ」のみ

## 5. コンテンツ方式（着手時に要判断）

| 方式 | 中身 | コスト | 推奨 |
|---|---|---|---|
| **A. 事前ストック型** | 20〜50本をクメール語＋英語で書きためて毎週1本自動投稿 | 無料 | ⭐ **まずこれ** |
| **B. AI自動生成型** | 毎週 Claude API が新ネタを生成して投稿 | API課金（少額） | △ 品質レビュー必須 |
| **A+B ハイブリッド** | AIが下書き → 人がスプシで添削 → 自動投稿 | API課金 | ◎ 軌道に乗ったら |

- 最初は **A（無料・クメール語品質を人が担保）** で立ち上げる。
- AI案は **API課金が発生するため、採否は Daisuke の判断**（経営コックピットの方針に準拠）。

## 7. 配信ネタ案（「日本の常識・カンボジアの非常識」）

- ☀️ 炎天下の洗車がなぜ塗装を痛めるか（カンボジアの強い日差し）
- 🌧️ 雨季（5〜10月）の正しいケア — 泥・下回りの錆対策、車内のカビ防止
- 🦅 鳥のフン・樹液を即取るべき理由（クリア層が侵される）
- 🌀 安い路上手洗いで付く「洗車キズ（スワール）」 → Samuraiの品質との差別化
- 💧 コーティングの撥水が効く仕組みと、持続させる洗い方
- 💺 高温多湿での車内衛生・エアコンフィルター
- 🛞 高温下でのタイヤ・ゴム類の劣化対策
- 🚙 定期的な洗車がリセールバリュー（下取り価格）を守る話

半年分（約25本）あれば回り始める。
