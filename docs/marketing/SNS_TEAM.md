## 4. チーム共通ルール（全員厳守）

1. **言語ルール**: 顧客向けはクメール語＋英語（クメール語が先）。顧客に日本語を見せない。社内文書・レポートは日本語。クメール語はドラフト扱いで必ずネイティブ確認（Bopha/ロン）を経る。
2. **2価格分離**: Telegram限定特価（$5等）は配信コピー内のみ。料金シート・ミニアプリ・Facebook公開投稿には絶対に載せない。
3. **配信時刻**: 00/15/30/45刻み（GAS 15分トリガー仕様）。推奨は朝08:00・夕18:30。日曜は定休で配信対象外。
4. **数字は推測しない**: 価格・日付・KPIは確定値のみ。曖昧ならユーザーに確認。
5. **本番データ保護**: シートは原則読み取り。書き込み（キャンペーン下書き投入等）はユーザー承認後の別タスク。
