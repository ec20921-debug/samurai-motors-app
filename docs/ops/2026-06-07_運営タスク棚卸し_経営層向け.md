## 凡例

**難易度**
- 易 … その場・短時間で完了（〜数時間）
- 中 … 準備や資料作成が必要（数日〜1週間）
- 難 … 相手との交渉・継続的な仕組み化が必要（数週間〜）

**ステータス**
- 完了 … 対応済み
- 着手可 … すぐ始められる
- 要調整 … 社外・現場との調整が前提
