# SPEC — 現場小口現金（前渡し金）残高トラッキング

**ステータス**: 仕様確定 / 実装待ち
**実装予定**: 2026-05-18 以降（飯泉さんカンボジア出張時、ロンと現地相談後）
**対象プロジェクト**: v7-operations
**作成**: 2026-05-12

---

## 背景

飯泉さんが ABA で現地スタッフのロンに数十ドルを送金し、ロンがそれを使って細かい経費を入力していく運用。現状の課題：

- 残高把握が毎回手動で「あといくら？」とやり取りする必要がある
- 補充タイミングを逃しがち
- 過去の補充・引落しの履歴がどこにも残っていない

---

## ゴール

1. ロンが経費を入れるたびに、管理グループ通知に **残金が併記**される
2. 残金が閾値（USD 10）を切ったら **⚠️ 補充推奨** が出る
3. 飯泉さんが ABA 送金後、ミニアプリから補充を記録すると残高に即反映
4. 全ての補充・引落しが履歴として残る

---

## スコープ（最小）

- **対象保有者**: ロンのみ（将来スタッフ全員に汎用化可能な設計にしておく）
- **対象通貨**: USD のみ（KHR/JPY は今回スコープ外）
- **補充入力**: 飯泉さんが `expense-internal.html` に新設する補充タブから

---

## データモデル

### 新シート `現金口座`

保有者ごとの現在残高。1行=1人。

| 列名 | 例 | 備考 |
|---|---|---|
| 保有者 | `ロン` | スタッフマスター `nameJp` と一致 |
| 通貨 | `USD` | 当面 USD 固定 |
| 残高 | `12.30` | `現金移動` の合計と一致するよう常時更新 |
| 補充推奨閾値 | `10` | これを下回ったら通知 |
| 最終更新 | `2026-05-12 12:16` | デバッグ用 |

### 新シート `現金移動`

全トランザクション履歴。

| 列名 | 例 |
|---|---|
| 移動ID | `CASH-20260512-001`（generateDateSeqId 流用） |
| 日時 | `2026-05-12 12:16` |
| 種別 | `補充` / `引落し` / `初期設定` / `調整` |
| 保有者 | `ロン` |
| 通貨 | `USD` |
| 金額（符号付き） | `+50` / `-3.50` |
| 残高（処理後） | `46.50` |
| 関連経費ID | `EXP-20260512-002`（引落しの場合） |
| 摘要 | `チラシのポスター購入` / `ABA送金 飯泉→ロン` |
| 登録者 | `飯泉` / `ロン` |

**設計理由**: 残高は `現金移動` 全行の SUM で検証できる二重簿記。`現金口座.残高` はキャッシュ用途（通知高速化）。整合性が崩れた場合は再計算可能。

---

## 経費登録フローの変更

`ExpenseManager.gs` の `paymentType` に区分を追加：

| 区分 | 説明 | 残高への影響 |
|---|---|---|
| `立替` | 後で精算（既存） | なし |
| `会社直払い` | 会社負担（既存） | なし |
| `前渡し` | **新規** ロンが保有現金から支払い | 引落し |

`前渡し` で経費登録された場合：
1. 通常通り `経費` シートに行追加
2. `現金移動` に `引落し` 行追加（関連経費ID 紐付け）
3. `現金口座.残高` を更新
4. 管理グループ通知に残金を併記

---

## 通知フォーマット

経費トピックへの通知（既存 `notifyExpenseCreatedIfField_` 拡張）：

```
🆕 経費追加（現場から）
👤 ロン
📋 EXP-20260512-002
💰 USD 3.50
📝 チラシのポスター
🏪 iBC
💳 区分: 前渡し
━━━━━━━━━━
💵 ロン残金: USD 46.50
```

閾値割れ時は末尾に追記：

```
⚠️ 残金が USD 10 を下回りました。補充してください。
```

残高マイナス時は強調：

```
⚠️ 残金マイナス: USD -3.50
```

## 補充フロー（飯泉さん）

1. 飯泉さん、ABA でロンに送金（例: USD 50）
2. `expense-internal.html` を開く → 「💴 現金補充」タブ
3. 入力: 保有者=ロン / 金額=50 / 通貨=USD / 摘要=「ABA送金」（任意）
4. 確定 → `現金移動` に `補充` 行追加 → `現金口座.残高` 加算
5. 管理グループ通知:

```
✅ 現金補充
👤 飯泉 → ロン
💴 USD 50
💵 ロン残金: USD 96.50
```

## 初期残高セットアップ

セットアップ関数 `ensureCashAccountsSheet()` で：
- `現金口座` シートを作成（ヘッダーのみ）
- `現金移動` シートを作成（ヘッダーのみ）

初回運用時、補充タブから `種別=初期設定` で「ロンが今持ってる金額」を1回入力する。

## エッジケース

| ケース | 対応 |
|---|---|
| 経費を間違って登録 → 削除/編集 | 当面は手動でシート行を消す + `現金移動` の対応行も消す（運用上ほぼ起きないので最小実装）。将来「取消」ボタン検討。 |
| 通貨ミスマッチ（KHR で登録） | バリデーションで弾く（前渡しは USD のみ） |
| 残金マイナス | 引落しは許容（記録優先）。通知に強調表示。 |
| 飯泉さん自身の前渡し | スコープ外。UI で `前渡し` 区分はロンのみ選択可とする。 |
| 同じ補充の二重登録 | 直前 5 分以内に同額同保有者の補充があれば確認ダイアログ（任意、フェーズ2） |
