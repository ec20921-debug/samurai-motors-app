- 新ファイル `ProspectImport.gs`（GAS エディタから実行）:
  1. スクリプトプロパティ `PROSPECT_LIST_SPREADSHEET_ID` = `1hdqIFXA9JFN-UN5P72nlIxrablEtQpi7xBHUan6ReQA`
  2. `prospectImportPreview()` → v7 Database に「見込み取込_確認」タブ（書き込みはこのタブだけ）。2026-10-19 時点のデータでクラウド試算: **追加 107 / 重複 134 / 要確認 3 / 対象外 7（競合6・自社1）**。要確認 = No.9 S-Auto Global ↔ S Auto、No.17 RTN Auto Garage（クメール名付き）↔ RTN Auto Garage、No.49 LD9 Auto Car ↔ 3IN1-Auto（8/3 にも中確度の重複として記録あり）。判定列を「追加」か「重複」に書き換える

## ヒアリングメモ（同日追加・Daisuke「任意でも枠は入れたい。何個も入れられるように。まとめは AI に」）

- 店の画面に「🗒 ヒアリングメモ」: 1行書いて「追加」を何回でも。下に新しい順で並ぶ（日時・書いた人）

## PC でのデプロイ手順（新アクションがあるので clasp deploy まで必要）

1. このブランチを取り込む: `git fetch origin claude/picasso-campaign-response-9jlthu && git checkout claude/picasso-campaign-response-9jlthu`
2. GAS（v7-operations）:
   ```bash
   cd v7-operations
   clasp push --force
   clasp deploy --deploymentId <本番のデプロイID>   # これを忘れると /exec が旧版のまま（UNKNOWN_ACTION）
   ```
3. 一本化: 上の「営業リストの一本化」の 1→2（確認タブを見て要確認3件を判断）→3 を実行。実行後、ミニアプリの地図に白いピンが約100本出ること
4. GAS エディタで `debugSalesHearingPrices` を1回実行 → ログに5件（HEADLIGHT 15 / HEADLIGHT_MAGIC 30 / GLASS_3 15・20 / GLASS_ALL 30・40 / WASH 12・15）が出ること
5. ミニアプリ配信: docs/DEPLOY.md の「ミニアプリ同期」を実行（`saleslog-internal.html` は既に同期リストに入っている）
6. 実機確認（ロン君の Telegram で）:
   - 白いピンの店で「追記」→ 次にやること・期日を入れて保存 → その店が「営業中」に変わり、期日が来るとホームの「今日やるフォロー」に出る
   - 一覧で「🧭 近い順」→ 位置情報の許可 → 距離が出る
   - 地図で青い点・文字入りピン・吹き出しの「前回」が出る
