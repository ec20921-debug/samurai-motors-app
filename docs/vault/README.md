# 🗄️ Samurai Motors Vault（ナレッジ保管庫）

このディレクトリは、Samurai Motors の**背景・状況・体制・意思決定**を集約した保管庫です。
各エージェント（政宗＝GM、利休＝ブランド）は、作業前に必ずここを参照して文脈を揃えます。

## 収録ファイル

| ファイル | 内容 |
|---|---|
| `00_business_context.md` | 事業概要・市場・システム構成・現在地（背景と状況） |
| `01_org_and_roles.md` | 体制図・役割分担・エスカレーション基準 |
| `02_initiatives_status.md` | 進行中の施策（SNS自動投稿・TikTok動画・キャンペーン等）の最新ステータス |
| `03_decisions_log.md` | 主要な意思決定の記録（日付・内容・決裁者） |

## 運用ルール

- 状況が動いたら **`02_initiatives_status.md`** を更新する。
- 決まったことは **`03_decisions_log.md`** に1行追記する（日付・決裁者を明記）。
- vault は「最新の真実」を保つ場所。古くなった記述は更新し、放置しない。
