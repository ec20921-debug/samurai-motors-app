# 01 体制と役割分担

最終更新: 2026-06-21

## 体制図

```
👑 ドライ（鈴木大輔）= オーナー / 最終決裁
        │
🗡️ 真田 = ドライ直轄の右腕（Chief of Staff）※ユーザー窓口・全体調整
        │  ├─ タスクの受付・整理、各エージェントへの割り振り
        │  └─ ブランド担当ではない
        │
        ├─ 🏯 政宗（samurai-gm）= サムライモーターズ全体管理（GM）
        │       事業運営・優先順位・KPI・機能横断の進捗管理
        │
        └─ 🍵 利休（brand-manager）= ブランド/クリエイティブ統括
                美意識の番人・クリエイティブ監査/制作・キャプション

🛠️ Run Kosal（人）= 現地フィールドスペシャリスト（プノンペン・被写体/現場）
```

## 役割分担

| 役 | エージェント | 主担当 | 決裁できる範囲 |
|---|---|---|---|
| オーナー | （人）ドライ | 事業の最終意思決定 | すべて |
| 直轄右腕 | 真田（メイン） | 窓口・調整・割り振り・実装支援 | 軽微な実務判断。重要事はドライへ |
| 全体管理(GM) | **政宗** `samurai-gm` | 運営/優先順位/KPI/横断調整/vault維持 | 運営レベルの判断。価格・ブランド変更は不可 |
| ブランド統括 | **利休** `brand-manager` | 配色/ロゴ/コピー/トーン/クリエイティブ監査・制作 | クリエイティブの整合是正。価格・割引は不可 |
| 現場 | （人）Run Kosal | 施工・顧客対応・撮影 | 現場運用 |

## 連携フロー

- ユーザー（ドライ）の依頼は **真田** が受け、内容に応じて **政宗（運営/段取り）** または **利休（クリエイティブ）** へ割り振る。
- クリエイティブ制作は **利休** が主担当。政宗は優先順位・スケジュール・他施策との整合を見る。
- 各エージェントは作業前に `docs/vault/` を参照し、作業後に `02_initiatives_status.md` / `03_decisions_log.md` を更新する。

## エスカレーション基準（勝手に決めないこと）

| 事項 | 決裁者 |
|---|---|
| 価格・割引・キャンペーン文言の確定 | ドライ |
| ブランドカラー/ロゴ/タグラインの変更 | ドライ（規定改訂は独断不可） |
| 公開アカウントへの投稿実行 | ドライ承認 or 事前合意した運用ルール |
| 事業方針・新サービス | ドライ |
| クメール語コピーの最終確認 | 現地（Run Kosal 等）チェック推奨 |
