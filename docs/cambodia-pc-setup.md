# カンボジア現地スタッフPC セットアップ手順書

**対象**: 日本から持ち込む業務用 Windows 11 PC を、現地スタッフに使わせつつ日本から遠隔管理できる状態にする
**初版作成**: 2026-05-16
**想定スタッフ数**: 1名（将来 2〜3 名追加を想定した拡張可能設計）
**所要時間**: 2〜3 時間（ライセンス購入・再起動含む）

---

## 0. 必要なもの（着手前にチェック）

- [ ] Windows 11 PC（OS は Home でも Pro でも可、Home の場合は Step 1 で Pro 化する）
- [ ] Microsoft アカウント（鈴木）
- [ ] Wi-Fi 接続環境
- [ ] クレジットカード（Windows 11 Pro ライセンス購入用、約 13,824 円）
- [ ] スマートフォン（接続テスト用、AnyDesk アプリ）
- [ ] パスワード管理ツール（Notion or 1Password）
- [ ] 16 桁ランダムパスワード生成手段
  - 1Password の生成機能 / [https://1password.com/password-generator](https://1password.com/password-generator) / `Get-Random` 等

---

## 1. Windows 11 Home → Pro へのアップグレード

> Home でも基本のリモート操作はできるが、**グループポリシー・BitLocker・複数ユーザー管理**が Pro でないと使えないため、業務 PC は Pro 必須。

### 手順
1. `スタート` → `設定` → `システム` → `ライセンス認証`
2. 「エディションのアップグレード」セクションで `Microsoft Store に移動`
3. **Windows 11 Pro へのアップグレード** を購入（税込 13,824 円）
4. 購入後、自動でアップグレード処理 → 再起動
5. 再起動後、`設定` → `システム` → `バージョン情報` で **「エディション: Windows 11 Pro」** と表示されることを確認

### つまずきポイント
- Microsoft アカウントでサインインしていないと購入できない
- ライセンス認証が「デジタル ライセンス」で紐づいていることを確認

---

## 2. アカウント分離（最重要）

> スタッフが標準ユーザーで動かすことで、勝手なソフトインストール・設定変更を防ぐ。これが最大の防御線。

### 2-1. 管理者アカウント（鈴木用）

- 既存のメイン Microsoft アカウントを使用
- アカウントの種類が「管理者」になっていることを確認
  - `設定` → `アカウント` → `ユーザーの情報` で「管理者」表示
- このアカウントのパスワードは **絶対にスタッフに教えない**

### 2-2. スタッフ用「標準ユーザー」アカウントの作成

1. `設定` → `アカウント` → `他のユーザー`
2. 「アカウントの追加」をクリック
3. 「このユーザーのサインイン情報がありません」をクリック
4. 「Microsoft アカウントを持たないユーザーを追加する」をクリック
5. 以下を入力：
   - **ユーザー名**: `samurai-staff`（または `cambodia-pc-01`）
   - **パスワード**: スタッフに伝える 8〜12 桁（複雑すぎず、覚えやすい）
   - **秘密の質問**: 3 つ設定（パスワード忘れ時の復旧用）
6. 作成後、追加されたアカウントをクリック → 「アカウントの種類の変更」
7. **「標準ユーザー」のまま** にする（管理者にしない）

### 2-3. スタッフ用アカウントで初回ログイン
- 一度サインアウト → スタッフアカウントでサインイン
- 初期設定（地域・キーボード等）を済ませる
- デスクトップに業務必須のショートカット（Chrome、AnyDesk、業務 Bot など）を配置
- 再度サインアウト → 管理者アカウントに戻る

## 3. 電源・スリープ設定

> スリープすると AnyDesk で繋がらなくなる。**スリープ無効化が必須**。

### 手順
1. `設定` → `システム` → `電源とバッテリー` → `画面とスリープ`
2. 以下に設定：
   - 電源接続時に画面の電源を切る: **15 分**
   - 電源接続時に PC をスリープ状態にする: **「なし」**
   - バッテリー使用時にスリープ状態にする: **「なし」**（ノート PC の場合）
3. `電源モード` を **「最適なパフォーマンス」** に変更
4. スタッフアカウントでも同じ設定になっていることを確認（必要なら両アカウントで設定）

### BIOS で「停電復旧時の自動起動」を有効化（推奨）
カンボジアは停電が起きやすい。電源復旧後に自動で PC が起動するように：
1. PC を再起動 → メーカーロゴ表示中に `F2` / `Del` / `F12`（機種による）で BIOS 起動
2. `Power` または `Advanced` メニュー
3. **「AC Power Loss」「Restore on AC Power Loss」** 等の項目を **「Power On」** または **「Last State」** に変更
4. 保存して再起動

## 4. Windows Update のスケジュール調整

> 業務時間中に自動再起動が走ると遠隔接続が切れる。**カンボジア深夜（日本朝）に固定**する。

### 手順
1. `設定` → `Windows Update` → `詳細オプション` → `アクティブ時間`
2. **手動で設定**：
   - 開始: 7:00（カンボジア時間 = 日本時間 9:00）
   - 終了: 22:00（カンボジア時間 = 日本時間 0:00）
   → この時間帯は再起動しない
3. **時刻と地域**を確認：
   - `設定` → `時刻と言語` → `日付と時刻` で **タイムゾーンを「(UTC+07:00) バンコク, ハノイ, ジャカルタ」** に変更
   - これでカンボジア現地時刻が PC に正しく反映される

## 5. AnyDesk セットアップ（リモート管理の本体）

### 5-1. インストール
1. ブラウザで [https://anydesk.com/ja](https://anydesk.com/ja) → 「AnyDesk をダウンロード」
2. ダウンロードした `AnyDesk.exe` を**管理者として実行**
3. 起動後、画面右の **「AnyDesk をこのコンピュータにインストール」** をクリック
4. インストールオプション：
   - [x] AnyDesk へのショートカットをデスクトップに作成
   - [x] AnyDesk をシステムにインストール
   - [x] **このコンピューターへの無人アクセスを許可する** ← 必須
5. インストール完了

### 5-2. 無人アクセスパスワード設定（最重要）
1. AnyDesk 画面の右上 `≡` → `設定` → `セキュリティ`
2. 「設定のロックを解除」（管理者パスワード入力）
3. **「無人アクセスを許可」** にチェック
4. **「無人アクセスのパスワードを設定」** をクリック
5. **16 桁ランダムパスワード** を入力（生成ツールで作成）
   - ❌ `samurai2026` のような推測可能なものは絶対 NG
   - ✅ `K9!mP2$xQ7@wL4nR` のようなランダム英数字記号
6. パスワード強度が「強い」と表示されることを確認

### 5-3. AnyDesk ID の確認・保管
1. AnyDesk のメイン画面に表示される **9 桁の ID**（例: `123 456 789`）をメモ
2. Notion / 1Password に以下を保管：
   ```
   サムライモーターズ カンボジア店舗 PC #1
   - AnyDesk ID: XXX XXX XXX
   - 無人アクセス PW: (16 桁ランダム)
   - Windows ユーザー: samurai-staff
   - Windows PW: (スタッフに伝えたパスワード)
   - PC シリアル番号: (本体裏に記載)
   - 設置場所: プノンペン店舗
   - 設置日: 2026-05-19
   ```

### 5-4. 起動時自動起動の確認
1. AnyDesk 設定 → `一般`
2. **「Windows 起動時に AnyDesk を起動」** にチェック
3. `設定` → `アプリ` → `スタートアップ` で AnyDesk が「オン」になっていることを確認

### 5-5. ファイアウォール例外（通常自動だが念のため確認）
- `設定` → `プライバシーとセキュリティ` → `Windows セキュリティ` → `ファイアウォールとネットワーク保護`
- 「アプリにファイアウォールを許可」で AnyDesk が「プライベート」「パブリック」両方にチェックされていることを確認

## 6. 接続テスト（スマホ 4G から実施）

> 自宅 Wi-Fi から接続すると同一 LAN 内になり、実環境のシミュレーションにならない。**必ずスマホ 4G/5G から実施**。

### 手順
1. PC 側：AnyDesk が起動した状態、サインアウト or 画面ロック状態にする（スタッフ不在の状態を再現）
2. スマホ側：Wi-Fi を**オフ** → モバイル回線（4G/5G）に切り替え
3. スマホに **AnyDesk アプリ** をインストール（App Store / Google Play）
4. アプリで PC の AnyDesk ID を入力 → 接続
5. 無人アクセスパスワードを入力
6. 画面が表示されれば成功 ✅

### テスト項目（チェックリスト）
- [ ] 画面が表示される
- [ ] マウス操作ができる
- [ ] キーボード入力ができる（半角英数字、日本語、クメール語）
- [ ] ファイル転送ができる（スマホ → PC、PC → スマホ）
- [ ] 音声通話が可能（必要なら）
- [ ] 切断後、再接続できる

### つまずき時の確認
- PC がスリープしていないか → 設定見直し
- AnyDesk アイコンがタスクバーにあるか → なければ起動
- ファイアウォールで AnyDesk がブロックされていないか
- 無人アクセスパスワードが間違っていないか（コピペ推奨）

- 個人利用（SNS、ゲーム等）は禁止

## 8. 月次メンテナンス（日本側で実施）

毎月 1 回、深夜のカンボジア時間（日本の朝）にリモートで実施：

- [ ] PC を再起動（メモリリーク予防）
- [ ] Windows Update の状態確認（保留中があれば適用）
- [ ] AnyDesk のバージョン確認・更新
- [ ] ディスク空き容量確認（C: ドライブ 20GB 以上空きを維持）
- [ ] Windows Defender でクイックスキャン
- [ ] 不要ファイル削除（ダウンロードフォルダ、ゴミ箱）
- [ ] スタッフからの困りごとヒアリング（Telegram で）

## 9. トラブルシューティング

### Q1. AnyDesk で繋がらない
1. Telegram でスタッフに「タスクバー右下に **AnyDesk の赤いアイコン**があるか確認してください」と聞く
2. アイコンがない場合：「Windows キー → `AnyDesk` と入力 → アイコンをクリック」と指示
3. それでもダメ → 「PC を再起動してください」と依頼
4. 再起動後も繋がらない → スタッフのスマホに AnyDesk アプリを入れて、スタッフ側から日本に発信してもらう（リバース接続）

### Q2. スタッフが Windows パスワードを忘れた
1. 日本から AnyDesk で接続（管理者は常に接続可能）
2. 管理者アカウントに切替（Ctrl+Alt+Del → ユーザーの切り替え）
3. `設定` → `アカウント` → `他のユーザー` → スタッフユーザー → `パスワードの変更`
4. 新パスワードをスタッフに Telegram で伝達

### Q3. 停電後 PC が起動しない
- BIOS の「AC Power Loss」設定を確認（Step 3 参照）
- 設定済みでも起動しない場合は、現地スタッフに電源ボタン押下を依頼

### Q4. 動作が重くなった
- まず再起動
- タスクマネージャーでメモリ・CPU 使用率の高いプロセスを特定
- 不要な常駐ソフトを `設定` → `アプリ` → `スタートアップ` から無効化
- ディスク空き容量を確認

### Q5. 回線が不安定
- 短期的対策：モバイルルーター（バックアップ回線）を予備で用意
- 長期的対策：UPS（無停電電源装置、5,000 円程度）で停電時のルーター電源確保

## 10. 将来スタッフが増えた時の追加手順

スタッフ 2 人目、3 人目を増やす時：

1. 同じ PC を共有する場合 → Step 2-2 を繰り返して標準ユーザーを追加
2. PC を増やす場合 → 新 PC で Step 1〜6 を実施
3. Notion の「Samurai Motors カンボジア PC 台帳」に追記
4. **スタッフが 3 名を超えたら、Microsoft Intune への移行を検討**
   - Microsoft 365 Business Premium（月 3,000 円/人）に含まれる
   - 一括ポリシー適用・紛失時リモートワイプ・ソフト配布が可能
   - 切替時期の目安：累計 PC 台数 3 台 or スタッフ 3 名超
