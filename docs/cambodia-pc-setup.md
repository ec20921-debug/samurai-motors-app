# カンボジア現地スタッフPC セットアップ手順書（貸出PC版）

**対象**: GNPC から貸出された Windows 11 PC を、カンボジア出張中に業務利用しつつ日本から遠隔管理する手順
**初版作成**: 2026-05-16
**運用開始**: 2026-05-19（プノンペン到着翌日）
**想定スタッフ数**: 1名
**所要時間**: 1〜2 時間（PCがセットアップ済みのため大幅短縮）

---

## 0. PC 情報（貸出元から提供済み）

| 項目 | 値 |
|---|---|
| 貸出元 | GNPC |
| OS | Windows 11（最新版） |
| Office | Word / Excel インストール済み |
| 管理者アカウント | ID: `GNPC-03` / PW: `adm_n03_03` |
| 一般アカウント | ID: `visitor` / PW: `visitor` |

### ⚠️ 重要：Windows パスワード変更ポリシー

- **本運用では Windows PW を変更しない方針**（GNPC-03 / visitor とも貸出時のまま使用）
- 理由：貸出元から「PW 変更時は返却後に再設定が必要」と指示あり。変更忘れによる返却トラブルリスクを回避
- セキュリティ：**AnyDesk の無人アクセスパスワード（16桁ランダム）が事実上の唯一の防御線**になるため、設定を厳格にする

## 3. 電源・スリープ設定（GNPC-03 で実施）

> スリープすると AnyDesk で繋がらなくなる。**スリープ無効化が必須**。

### 手順
1. `GNPC-03` でサインイン（PW: `adm_n03_03`）
2. `設定` → `システム` → `電源とバッテリー` → `画面とスリープ`
3. 以下に設定：
   - 電源接続時に画面の電源を切る: **15 分**
   - 電源接続時に PC をスリープ状態にする: **「なし」**
   - バッテリー使用時にスリープ状態にする: **「なし」**（ノート PC の場合）
4. `電源モード` を **「最適なパフォーマンス」** に変更

### BIOS で「停電復旧時の自動起動」を有効化（推奨）

カンボジアは停電が起きやすい。電源復旧後に自動で PC が起動するように：

1. PC を再起動 → メーカーロゴ表示中に `F2` / `Del` / `F12`（機種による）で BIOS 起動
2. `Power` または `Advanced` メニュー
3. **「AC Power Loss」「Restore on AC Power Loss」** 等を **「Power On」** または **「Last State」** に変更
4. 保存して再起動

⚠️ BIOS 設定変更は貸出元への影響あり → **返却前に元の設定（通常 `Power Off`）に戻す**

## 4. Windows Update のスケジュール調整（GNPC-03 で実施）

> 業務時間中に自動再起動が走ると遠隔接続が切れる。**カンボジア深夜（日本朝）に固定**する。

### 手順
1. `設定` → `時刻と言語` → `日付と時刻` で **タイムゾーンを「(UTC+07:00) バンコク, ハノイ, ジャカルタ」** に変更
2. `設定` → `Windows Update` → `詳細オプション` → `アクティブ時間`
3. **手動で設定**：
   - 開始: 7:00（カンボジア時間）
   - 終了: 22:00（カンボジア時間）
   → この時間帯は再起動しない

## 5. AnyDesk セットアップ（GNPC-03 で実施、最重要）

> 管理者権限が必要なので必ず GNPC-03 でログインして実施。

### 5-1. インストール
1. ブラウザで [https://anydesk.com/ja](https://anydesk.com/ja) → 「AnyDesk をダウンロード」
2. ダウンロードした `AnyDesk.exe` を**管理者として実行**
3. 起動後、画面右の **「AnyDesk をこのコンピュータにインストール」** をクリック
4. インストールオプション：
   - [x] AnyDesk へのショートカットをデスクトップに作成
   - [x] AnyDesk をシステムにインストール
   - [x] **このコンピューターへの無人アクセスを許可する** ← 必須

### 5-2. 無人アクセスパスワード設定（最重要）

> **Windows PW は変更しない方針のため、AnyDesk PW が事実上の唯一の防御線。
> 必ず 16 桁の強力なランダムパスワードで設定する。**

1. AnyDesk 画面の右上 `≡` → `設定` → `セキュリティ`
2. 「設定のロックを解除」（管理者パスワード入力 = `adm_n03_03`）
3. **「無人アクセスを許可」** にチェック
4. **「無人アクセスのパスワードを設定」** をクリック
5. **16 桁ランダムパスワード** を入力（1Password の生成機能等で作成）
   - ❌ `samurai2026` / `cambodia01` / 店名等の推測可能なものは絶対 NG
   - ✅ `K9!mP2$xQ7@wL4nR` のようなランダム英数字記号
6. パスワード強度が「強い」と表示されることを確認

### 5-3. AnyDesk ID の確認・保管

1. AnyDesk のメイン画面に表示される **9 桁の ID**（例: `123 456 789`）をメモ
2. Notion / 1Password に以下を保管：

```
サムライモーターズ カンボジア店舗 PC #1（貸出PC GNPC-03）
- 貸出元: GNPC
- AnyDesk ID: XXX XXX XXX
- AnyDesk 無人アクセス PW: (16 桁ランダム)
- Windows GNPC-03 PW: adm_n03_03（貸出元提供、変更なし）
- Windows visitor PW: visitor（貸出元提供、変更なし）
- 設置場所: プノンペン店舗
- 設置日: 2026-05-19
- 貸出元連絡先: (GNPC 担当者)
- 返却期限: (未定 / 確定したら追記)
```

### 5-4. 起動時自動起動の確認

1. AnyDesk 設定 → `一般`
2. **「Windows 起動時に AnyDesk を起動」** にチェック
3. AnyDesk が **Windows サービスとして動作** することを確認
   → これにより `visitor` でログインしている時もリモートアクセス可能
4. `設定` → `アプリ` → `スタートアップ` で AnyDesk が「オン」になっていることを確認

### 5-5. ファイアウォール例外の確認
- `設定` → `プライバシーとセキュリティ` → `Windows セキュリティ` → `ファイアウォールとネットワーク保護`
- 「アプリにファイアウォールを許可」で AnyDesk が「プライベート」「パブリック」両方にチェックされていることを確認

## 7. 接続テスト（スマホ 4G から実施）

> 自宅 Wi-Fi から接続すると同一 LAN 内になり、実環境のシミュレーションにならない。**必ずスマホ 4G/5G から実施**。

### 手順
1. PC 側：`visitor` でログインしたまま画面ロック（`Win+L`）
2. スマホ側：Wi-Fi を**オフ** → モバイル回線（4G/5G）に切り替え
3. スマホに **AnyDesk アプリ** をインストール（App Store / Google Play）
4. アプリで PC の AnyDesk ID を入力 → 接続
5. 無人アクセスパスワードを入力
6. 画面が表示されれば成功 ✅

### テスト項目（チェックリスト）
- [ ] 画面が表示される
- [ ] マウス操作ができる
- [ ] キーボード入力ができる（半角英数字、日本語、クメール語）
- [ ] ファイル転送ができる（スマホ → PC、PC → スマホ）
- [ ] visitor → GNPC-03 への切替ができる（ユーザー切替経由）
- [ ] 切断後、再接続できる

### つまずき時の確認
- PC がスリープしていないか → 設定見直し
- AnyDesk アイコンがタスクバーにあるか → なければ起動
- ファイアウォールで AnyDesk がブロックされていないか
- 無人アクセスパスワードが間違っていないか（コピペ推奨）

## 10. トラブルシューティング

### Q1. AnyDesk で繋がらない
1. Telegram でスタッフに「タスクバー右下に **AnyDesk の赤いアイコン**があるか確認してください」と聞く
2. アイコンがない場合：「Windows キー → `AnyDesk` と入力 → アイコンをクリック」と指示
3. それでもダメ → 「PC を再起動してください」と依頼
4. 再起動後も繋がらない → スタッフのスマホに AnyDesk アプリを入れて、スタッフ側から日本に発信してもらう（リバース接続）

### Q2. スタッフが Windows パスワードを忘れた
- visitor のパスワードは `visitor`（固定）なので、口頭で再伝達
- 万一変更してしまった場合 → AnyDesk で GNPC-03 経由でログインして visitor のパスワードをリセット → 再度 `visitor` に設定

### Q3. 停電後 PC が起動しない
- BIOS の「AC Power Loss」設定を確認（Step 3 参照）
- 設定済みでも起動しない場合は、現地スタッフに電源ボタン押下を依頼

### Q4. 動作が重くなった
- まず再起動
- AnyDesk 経由で `GNPC-03` でログイン → タスクマネージャーで原因プロセスを特定
- 不要な常駐ソフトを `設定` → `アプリ` → `スタートアップ` から無効化

### Q5. 回線が不安定
- 短期的対策：モバイルルーター（バックアップ回線）を予備で用意
- 長期的対策：UPS（無停電電源装置、5,000 円程度）で停電時のルーター電源確保

## 11. 🔄 返却前のクリーンアップ手順（重要）

> **貸出 PC なので返却時に「貸出時の状態」に戻すことが必須**。
> 業務データの残置は情報漏洩リスク、設定変更の残置は貸出元への迷惑になる。

### 返却日が決まったら（返却 3 日前〜）

#### Step A. 業務データのバックアップ
1. AnyDesk 経由で `GNPC-03` でログイン
2. デスクトップ・ドキュメント・ダウンロードフォルダの業務データを Google Drive に全てバックアップ
3. ブラウザのブックマーク・パスワード等もエクスポート

#### Step B. インストールしたソフトのアンインストール
1. `設定` → `アプリ` → インストールしたソフトの一覧を確認
2. **5/17 のセットアップ以降にインストールしたものを全て削除**：
   - AnyDesk
   - その他追加した業務ソフト
3. アンインストール後、`C:\Program Files\` と `C:\Program Files (x86)\` の関連フォルダが残っていれば手動削除

#### Step C. 業務データの完全削除
1. デスクトップ・ドキュメント・ダウンロードフォルダの業務ファイルを削除
2. ゴミ箱を空にする
3. ブラウザの履歴・キャッシュ・Cookie・保存パスワードを全削除：
   - Chrome / Edge: `設定` → `プライバシーとセキュリティ` → `閲覧履歴データの削除` → 「全期間」「全項目」
4. visitor アカウントのプロファイル内の `AppData` 配下の業務関連ファイルも削除

#### Step D. 設定を元に戻す
1. 電源プラン → 元の「バランス」に戻す
2. スリープ設定 → 元の設定（通常 15〜30 分でスリープ）に戻す
3. Windows Update のアクティブ時間 → 自動に戻す
4. BIOS の AC Power Loss 設定 → 元の `Power Off` に戻す
5. タイムゾーン → 日本に戻す（または貸出元の指示通り）

#### Step E. 動作確認
1. PC を再起動
2. `GNPC-03` でログインできる（PW `adm_n03_03`）
3. `visitor` でログインできる（PW `visitor`）
4. デスクトップ・ドキュメントが空に近い状態
5. AnyDesk が削除されている
6. ブラウザの履歴等が空

#### Step F. 貸出元への返却報告
- **パスワードは変更していないので「変更後パスワードの報告」は不要**
- 「設定を元に戻しました、業務データは全て削除済みです」と一言伝える

### 返却前最終チェックリスト

- [ ] 業務データを全て Google Drive にバックアップ済み
- [ ] デスクトップ・ドキュメント・ダウンロードが空
- [ ] ゴミ箱が空
- [ ] AnyDesk アンインストール済み
- [ ] その他インストールしたソフト全て削除済み
- [ ] ブラウザの履歴・パスワード・Cookie 削除済み
- [ ] 電源・スリープ設定を元に戻した
- [ ] Windows Update アクティブ時間を自動に戻した
- [ ] BIOS の AC Power Loss を元に戻した
- [ ] タイムゾーンを元に戻した（必要なら）
- [ ] GNPC-03 でログイン確認（PW `adm_n03_03` で入れる）
- [ ] visitor でログイン確認（PW `visitor` で入れる）
- [ ] Notion 上の認証情報をアーカイブ（即削除はしない、3ヶ月後削除）
