# CHANGE_IMPACT_MAP.md — 変更影響マップ

> **Samurai Motors の運用ルール文書**
> 「何かを変えたら、他のどこも変える必要がある」を見落とさないためのチェックリスト集。
> 真田(Sanada)はコード変更/メニュー変更/価格変更等を実装した後、必ず本ファイルを参照し、
> 応答末尾に「📋 変更影響」セクションを付与する。

---

## 📌 このドキュメントの使い方

### 真田の運用ルール

実装/設定変更を完了したら、応答の**最後**に必ず以下のブロックを付ける:

```
📋 変更影響(CHANGE_IMPACT_MAP.md 準拠):
  ✅ 今回対応済: [list]
  ⬜ 未対応(要判断): [list]
  ➡️ 推奨次アクション: [1-2 件]
```

### Daisuke の判定

「✅ / ⬜」を見て、未対応のうち**どれを今やる/後でやる/不要**かを Daisuke が即断できる構造にする。
真田が勝手にやらないが、見落とさない。

### 改訂ルール

新しい「種類の変更」をやって、本マップに該当チェックリストが無ければ、
**その回の最後に本ファイルを追記**する(自己更新型)。

## 🎌 キャンペーン開始/終了

> 例: GRAND OPENING -30% を 2 週間限定で実施

### システム側(開始時)

- [ ] **Plan_Prices シート / campaign 行** — active=TRUE, percent, nameEn, nameKm, 期間
- [ ] **/start Welcome バナー** — getBookingConfig() 経由で自動反映(コード変更不要)
- [ ] **booking.html ヘッダーバナー** — apiBookingInit 経由で自動反映(コード変更不要)
- [ ] **料金計算ロジック** — discount = serviceSubtotal × percent / 100 が正しく入る確認

### システム側(終了時)

- [ ] **Plan_Prices.campaign / active=FALSE** に切替
- [ ] バナー/価格表示が自動的に通常価格に戻ることを確認
- [ ] **終了日のカレンダー予約** — 切替忘れ防止(Daisuke のカレンダー or 真田リマインダー)

### 顧客接点

- [ ] **Facebook 告知投稿** — キャンペーン開始時に大々的に
- [ ] **FB ピン留め切替** — 期間中はキャンペーン投稿をピン
- [ ] **チラシ** — 期間限定なら期日明記、期間外配布用は通常版を別に用意
- [ ] **既存顧客 DM** — リピート狙うなら期間中に1回プッシュ

### 終了後

- [ ] FB ピン留めを通常メニュー版に戻す
- [ ] 期間切れの投稿は「終了しました」コメントを付ける or 削除
