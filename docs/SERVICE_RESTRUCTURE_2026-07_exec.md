## 2. なぜ再構築するのか（現状認識）

1. **主力の無水洗車が構造的に不利。** 現地洗車場は内装・下回り込みで$5〜10。当社Wash $12〜15は同じ土俵で正面比較され、勝てていない（現状の苦戦そのもの）。
2. **一方、圧倒的に訴求が強い商材が実証済み。** 6/29のヘッドライト研磨デモは店頭で見せた場でそのまま受注につながった。撥水も雨季キャンペーンで「体験→受注」の型を実証済み。
3. **供給がボトルネック。** 施工者はロン君1名。上限は実測ベースで4件/日・月104件。**需要ではなく施工者数と提携店数が月商の上限を決めている。** 薄利の洗車で枠を埋めるほど機会損失が大きい。

## 3. 提案の骨子：全サービスの2軸評価

全サービスを「①訴求のしやすさ ②コスト（工数・技能・場所制約）」で評価し、役割を再配置した。

| | **コスト軽い** | **コスト重い** |
|---|---|---|
| **訴求強い** | 🏆 **主力**：ヘッドライト・ガラス撥水<br>→ 今すぐ量を売る入口兼収益源 | 🚩 **旗艦**：Body Refresh・ガラス傷除去<br>→ 定価見積制・値引き対象外。受注は常時・施工は束ねる「予約プール」 |
| **訴求弱い** | 🔄 **再定義**：Wash・車内清掃・サブスク<br>→ 単品集客をやめ、付帯・会員・束ね売りへ | 🔜 **将来枠**：内装・ホイールリペア<br>→ 技術未導入。B2Bパイロットと並行して技術獲得後に開放 |

**設計の本体は象限を跨ぐ導線**：入口（Wash/ヘッドライト）→ 現場診断 → 本命（ガラス全面・Body Refresh）→ 会員（Maintenance）→ リペア・物販。

### 主要な個別判断

- **Samurai Wash は「洗車」として売るのをやめ、3役割に転換**：①コーティング施工済み客のメンテ洗車（無水の弱点が技術的正当性に変わる）②水が使えない地下駐車場・法人車の唯一解 ③診断カルテつき入口（上位メニューへの送客装置）。
- **車内清掃は単品廃止候補**。パッケージ内・預り時の付帯へ退避。
- **サブスク（Maintenance）は施工済み客限定で育成**。母数が固まってから本格化（既定の順序どおり）。

## 5. B2B（中古車店）— 第2の収益エンジン

### 収益3レイヤー

| | 収益源 | 支払者 |
|---|---|---|
| ① 在庫商品化（リコン卸） | Light $99 / Standard $199 / Premium $399 | 店 |
| ② 販売時オプション紹介 | 小売価格×件数（店へ成約額20%キックバック） | 車の買い手 |
| ③ B2Cブランド育成 | 納車客→予約Bot登録→Maintenance転換 | 納車後の顧客 |

### 経営上のポイント

- **店の屋根付きスペースが高単価メニューの施工場所問題を解決する仮説。** 成立すればB2Bは売上チャネルであると同時に「磨き系は屋外不可」の制約の解になる（電源・粉塵・滞留時間はパイロット1店で要検証）。
- **移動ゼロの連続施工**で、ヘッドライトまとめ6台/日の試算では1日粗利がB2C出張の**約6倍**🔴（材料費仮置き）。
- 営業は**「ヘッドライト・トロイの木馬」**：初回訪問で商談せず、展示場の黄ばみ車1台を60分無料デモ→店主が自分の目で確認→後日Light受注→紹介制度へ。実証済みの「体験→信頼→後から制度」パターンの転用。
- **提案言語は「洗車サービス」ではなく「在庫回転率・成約率・再販価値を上げる利益創出ソリューション」**（Standard $199→提示価格+$500〜1,500、ROI 2.5〜7.5倍）。
- **パイロット条件**：1〜2店・3ヶ月・加盟金ゼロ・いつでも中止可。やめどき＝3ヶ月でリコン月2台未満 or 紹介ゼロ。
- **必須の備え**：他店の商品在庫に研磨機を当てる以上、デモ失敗時の補償方針を先に決める（1件の失敗で商圏の評判を失う）。

## 6. 集客の再設計（チラシ → Facebook中心）

```
(a) Facebook＝新規認知 → (b) Telegram公開チャンネル＝受け皿・育成（未着手・最優先開設）
 → (c) 予約Bot DM＝既存客販促（登録約97名） → (d) 紹介・パートナー＝高LTV
```

- **チラシは廃止せず用途限定**（B2B営業同行・施工現場の近隣配布・店頭置き）。スタッフの無差別手配りは停止し、その時間を施工＋撮影に振り替える。
- **FBはリール週3投稿から**（ヘッドライトBefore/After・撥水デモが主役）。撮影=ロン君（SOP化）、編集・投稿=日本側。
- **広告は少額テスト**：$5/日、**月上限$150**🔴（要承認）。誘導先は予約Botディープリンクで流入元を計測。やめどき＝問い合わせ1件$10超が2週継続。
- **キャパ連動**：予約が3日先まで満枠になったら広告停止（供給上限 月104件と連動）。
- **最初の一手はFB広告ではない**：最もCACが安いのは既存のTelegram登録97名・施工済み27件への直接提案。ここから着手する。

## 7. 採算性の要点

**実測済み**：ガラス3面98分・全面117分／ヘッドライト15〜60分/灯／撥水材$5/台。
**仮置き**🔴：人件費$2.0/h・移動実費・磨き系材料費。**材料原価の記録がほぼゼロなのが最大の穴 → 資材ログを今週開始する。**

### 値引きキャンペーンの構造転換（30%オフ耐性・フルコスト試算）

| サービス | 30%オフ後の粗利 | 判定 |
|---|---|---|
| ガラス全面 $30→$21 | **+$8.6（41%）** | 🟢 耐える → **値引き主役に切替** |
| ヘッドライト軽度 $15→$10.5 | **+$4.7（45%）** | 🟢 耐える → **値引き主役に切替** |
| 無水洗車 $12→$8.4 | +$0.9 | 🟡 ほぼトントン |
| ガラス3面 $15→$10.5 | ▲$0.3 | 🔴 赤字 |
| W23プロモ（$5/$10） | ▲$2.5〜4.8 | 🔴 明確な広告費と割り切る場合のみ |

**示唆**：30%オフの一律適用をやめ、①入口2商品に限定＋件数キャップ ②値引き主役を「ガラス全面」「ヘッドライト軽度」へ切替（値引いても黒字）③プレミアム・B2Bは値引き対象外。

### 月商の見通し（現体制・仮置き前提🔴）

ロン君1名・4件/日・月104件が供給上限。月商レンジは**約$1,500〜3,600**（デイリーのみ〜B2B混合＋技術者来訪月）。**成長の制約は需要ではなく供給。** 2人目採用の判断ライン設定が必要（§9参照）。

### 価格の一本化（メニュー公開前に必須）

現在3つの価格表（6月ドラフト／Total Repair README／五木田案）が併存し、序列逆転がある。統合ルール2つを先に決める：
1. **チャネル間の価格逆転禁止**（直接B2C価格 ≦ 店経由小売価格）
2. **卸=小売×0.6** を全メニュー共通ルール化

## 8. 主要リスク

| リスク | 対応方針 |
|---|---|
| **雨季の再施工保証コスト**（硬化前スコール水濡れは発生済み） | 無償再施工率を原価に織り込む。雨季は速乾材標準・耐熱コートは預り6時間確保とセット |
| **B2Bデモ失敗による評判毀損** | 補償方針を決めてから開始（§5） |
| **物損賠償・保険が未整備**（預り中事故・粉塵による隣接展示車汚損） | B2B店内施工の標準化前に枠組みを設計。店側が最初に聞く論点 |
| **ロン君1名依存** | 採用判断ライン（月商$X or B2B2店目）を先に決める |
| **ログが定着しない**（時刻ログ回収率 72件中5件） | Bot経由のワンタップ記録等、入力負荷の手当てなしでは採算の再計算が回らない |
| **既配布チラシに技術未導入メニューが掲載** | 回収/差し替え、または「要相談」注記の運用を決める |
| **B2B与信・税務**（支払条件・VAT・KB税務処理） | パイロット契約前に設計 |
