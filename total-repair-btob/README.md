# Samurai Motors ／ Total Repair B2B 事業パッケージ

日本の「トータルリペア（交換せず"補修"で直す総合カーリペア）」をカンボジア・プノンペンで TTP し、
**中古車店との提携で B2B 収益を作る**ための一式。提案書・顧客向けチラシ・管理システム設計・価格/キックバック設計をまとめる。

> 元ネタ: トータルリペア（米国発・日本で全国約460加盟店）。革シート・ダッシュボード・ステアリング・ホイール・ヘッドライト・外装小傷を **交換ではなく補修** で安く直す。
> カンボジア適合理由: 現地中古車はほぼ全部が米国等からの輸入中古。酷暑でダッシュのひび割れ・革の擦れ・ホイールのガリ傷・ヘッドライト黄ばみが"標準装備"。**補修ニーズが構造的に大きく、競合（高品質店）が少ない。**

## 💵 収益モデルは2系統（両方やる）

| | ① B2B リコンディション（卸） | ② 紹介キックバック（チラシの主役） |
|---|---|---|
| 誰が払う | **中古車店**（仕入れた車を出品前に整備） | **車の買い手**（店が紹介） |
| 店のメリット | 見栄え向上で「早く・高く」売れる | 何もせず**紹介するだけで現金収入** |
| Samurai収益 | 卸値だが台数が安定・まとめ施工で効率良い | 小売価格フル × 件数 |
| 価格 | リコンパッケージ（卸値） | 小売価格 |
| 店の取り分 | 転売利益の上振れ（店が丸取り） | 成約額の **20%** キックバック |

多くの店は **両方** 使う想定 → 高額車は自分でリコンして高く売り、買い手にはチラシで紹介してキックバックも得る。

## 💸 紹介キックバック設計

- **基本：紹介成約額の 20%**（初回施工分）。
  - 例）買い手が $69 のダッシュ補修 → 店に **$13.8**
  - 例）買い手が $199 の内装フルリカラー → 店に **$39.8**
- **インセンティブ**：1店あたり月10成約を超えた分は翌月 **+5%（合計25%）**。
- **支払い**：翌月15日締め・現金 or ABA送金（既存「前払い管理」と同じ送金導線）。領収はTelegram写真。
- **紹介の紐付け**：店ごとに固有の **紹介コード**（例 `SM-D001`）。
  - 顧客がチラシのQR/予約時にコード提示 → 自動で店に紐付け。
  - または店スタッフがTelegram業務Botで `/refer SM-D001 顧客名 電話` 送信。
- リコン（卸）は店が直接支払う取引なので **キックバック対象外**（二重取り防止）。

## 📈 ざっくり収益シミュレーション（仮定値・要検証）

前提：提携 **5店**、各店 月8紹介成約・平均単価 $80、各店 月4台リコン（Standard $199）。

| 項目 | 月額 |
|---|---|
| 紹介売上 | 5×8×$80 = **$3,200** |
| └ うちキックバック（店へ） | −$640（1店あたり平均 **$128/月**の不労収入） |
| リコン売上 | 5×4×$199 = **$3,980** |
| **B2Bチャネル月商 合計** | **約 $7,180** |

> ※材料費・出張/施工人件費は別途。数値は提携店数と稼働で線形に伸びる。まず1〜2店でパイロット → 実数で更新する。

## 🚀 立ち上げステップ（推奨）

1. **パイロット店を1〜2店選定**（日系/関係性のある中古車店が理想）。
2. 提案書（本フォルダ）で提携合意 → 紹介コード発行・チラシ設置。
3. リコン1台を**無料 or 原価**でデモ施工 → ビフォーアフターで効果を体感させる。
4. 管理は**まずGoogleスプレッドシート＋Googleフォーム**でMVP運用（`management_system_design.md` 参照）。
5. 回り始めたら Telegram業務Bot / ミニアプリへ段階拡張。
